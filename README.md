## 数据格式（每条提示词）

库中实际存储字段：`id, model, cat, sub, name, desc, tags, lang, langname, zh, original, src, srcs, primary, num, chars, sha1`。

**新增一条时，只需提供以下 9 个必填字段**，其余（`id / sha1 / chars / langname / num / primary / srcs`）由 `追加提示词.py` 自动计算：

| 字段 | 说明 |
|------|------|
| `model` | 模型，须写成「系列 + 空格 + 版本」，如 `Seedance 2.0` / `Seedance 2.5` / `海螺 H3` / `可灵 O3` |
| `cat` | 大类（如 `动作·打斗`、`创意转场·运镜`、`写实人物·剧情`） |
| `sub` | 子类 |
| `name` | 中文标题 |
| `desc` | 中文简介 |
| `tags` | 标签数组，**3–6 个**；中文标签或技术标签（`FPV`/`IMAX`/`CG`/`UE5`/`AI`/`VFX` 等） |
| `lang` | 语言：`zh` 或外文代码（如 `en`） |
| `original` | 提示词原文（中文直接放这；外文则放外文，`zh` 放译文） |
| `src` | 来源，如 `用户直供` 或 `seedance2.0收集6#1` |

可选：`zh`（外文条目必填中文译文）、`srcs`（来源文件列表）、`num`、`primary`。

示例（`新条目.json`，支持数组一次多条）：

```json
[
  {
    "model": "Seedance 2.0",
    "cat": "动作·打斗",
    "sub": "近身·格斗",
    "name": "雨夜巷战·慢镜近身",
    "desc": "雨水沿刀刃滑落，慢动作近身格斗，霓虹反光。",
    "tags": ["打戏", "慢动作", "雨夜", "AI视频"],
    "lang": "zh",
    "original": "雨夜巷战，慢镜头近身格斗，雨水沿刀刃滑落……",
    "src": "用户直供"
  }
]
```

## 让别的 AI / 协作者推送提示词

本功能面向「能跑 Python + 有仓库推送权限」的协作者（包括其它 AI 助手）。标准流程：

1. 整理新提示词为 `新条目.json`（9 必填字段，见上；可一次多条）。
2. 追加并自检：
   ```bash
   python 追加提示词.py "视频提示词库-多模型-191条-V1.1.html" 新条目.json
   ```
   工具会先备份、原地写回，并做完整校验（指纹不可变、无重复原文、字段/标签合规）。**校验不通过则不会写出任何文件。**
3. 只读核验（推荐）：
   ```bash
   python 库维护工具.py verify "视频提示词库-多模型-191条-V1.1.html"
   ```
   应全绿。
4. 推送：
   ```bash
   python git_push.py "追加 N 条：<简述>"
   ```
   推送需要仓库写权限与凭据（本机用 `.gh_token` + embedded URL，不弹窗）。

> 其它 AI 接入时务必遵守：① `original` 一个字符都不改（指纹校验会拦）；② 只追加、不改动版本号与文件名；③ 外文条目必须带 `zh` 译文；④ 标签 3–6 个。

## 铁律（不可破）

1. **只追加，不迭代版本**：文件名 `视频提示词库-多模型-191条-V1.1.html` 是固定句柄，只往里加，不 bump 版本号、不另存新文件。
2. `original` 不可变：改动会被指纹校验拦截。
3. 每次追加前自动备份到 `视频提示词库_备份/`（时间戳命名），可随时恢复。
4. 本地优先：权威副本始终在本地 D 盘；GitHub 仅作同步/备份与网页发布渠道。
